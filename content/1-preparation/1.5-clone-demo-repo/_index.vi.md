#### Clone Demo Repo
Ở bước này, chúng ta sẽ tiến hành clone các demo repo dành cho việc deploy các dịch vụ thử nghiệm.

1. Copy và Paste đoạn lệnh dưới đây vào Terminal của Cloud9 Workspace để tiến hành clone các demo repo.

```
cd ~/environment
git clone https://github.com/brentley/ecsdemo-frontend.git
git clone https://github.com/brentley/ecsdemo-nodejs.git
git clone https://github.com/brentley/ecsdemo-crystal.git
```
